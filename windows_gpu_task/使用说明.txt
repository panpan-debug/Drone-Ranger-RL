【Drone-Ranger-RL 训练任务 · 使用说明】

这份说明写给帮忙跑训练的朋友。全程不需要懂代码，按步骤来即可。
预计占用：首次准备约 10 分钟，训练数小时（电脑别合盖、别睡眠）。

═══════════════════════════════════════
第 0 步：安装 Python（只需一次）
═══════════════════════════════════════
1. 打开 https://www.python.org/downloads/ 下载 Python 3.12 左右的版本
2. 安装时【务必勾选】 "Add python.exe to PATH"（最底下那个勾），再点 Install

═══════════════════════════════════════
第 1 步：下载代码
═══════════════════════════════════════
1. 浏览器打开 https://github.com/panpan-debug/Drone-Ranger-RL
2. 点绿色 "Code" 按钮 → "Download ZIP"
3. 解压到任意位置（比如桌面）

═══════════════════════════════════════
第 2 步：放入起点模型（微信发你的那个文件）
═══════════════════════════════════════
1. 你会收到一个文件：nav100_3obs_init.pt（约 77KB）
2. 在解压出来的代码里找到 dqn_2d_standalone 文件夹
3. 在里面新建一个文件夹，命名为 checkpoints
4. 把 nav100_3obs_init.pt 放进 checkpoints 里
   最终路径应长这样：
   Drone-Ranger-RL-main\dqn_2d_standalone\checkpoints\nav100_3obs_init.pt

═══════════════════════════════════════
第 3 步：双击运行【1_安装环境.bat】（只需一次）
═══════════════════════════════════════
- 会自动创建虚拟环境并安装依赖，torch 比较大，耐心等几分钟
- 看到"安装完成"就可以关掉窗口

═══════════════════════════════════════
第 4 步：双击运行【2_开始训练.bat】
═══════════════════════════════════════
- 开始正式训练，共 3000 轮，需要数小时
- 期间窗口会一直滚动日志，属于正常现象
- 想中断可以随时 Ctrl+C（每 100 轮自动存档，不会全丢）
- 训练结束后会自动接着跑评估，不用再操作

═══════════════════════════════════════
第 5 步：把结果发回来
═══════════════════════════════════════
训练+评估全部完成后，把这两个文件发回来（微信即可，都很小）：
1. dqn_2d_standalone\eval_lc_final.csv
2. dqn_2d_standalone\checkpoints\curr_3obs_lc_final.pt

【常见问题】
Q: 我有显卡，为什么好像没用到？
A: 正常。这个实验环境是纯运动学计算，主要吃 CPU，显卡用不上不影响结果。

Q: 提示 "python 不是内部或外部命令"？
A: 第 0 步安装时没勾 "Add python.exe to PATH"，重装一遍 Python 并勾上。

Q: 中途想停怎么办？
A: 在训练窗口按 Ctrl+C。下次想接着跑，再双击一次【2_开始训练.bat】即可，
   它每 100 轮会自动保存进度（但注意：重新开始会从 0 轮计起，
   中断后请先联系项目方再决定怎么处理）。
