【Drone-Ranger-RL 训练任务 · 使用说明】

这份说明写给帮忙跑训练的朋友。全程不需要懂代码，按步骤来即可。
预计占用：首次准备约 10 分钟，之后双击一次脚本，自动跑完全部
2 个训练任务（共约 3 小时），中途无需任何操作。电脑别合盖、别睡眠。

═══════════════════════════════════════
第 0 步：安装 Python（只需一次）
═══════════════════════════════════════
1. 打开 https://www.python.org/downloads/ 下载 Python 3.12 左右的版本
2. 安装时【务必勾选】 "Add python.exe to PATH"（最底下那个勾），再点 Install

═══════════════════════════════════════
第 1 步：下载代码
═══════════════════════════════════════
1. 浏览器打开 https://github.com/panpan-debug/Drone-Ranger-RL
2. 点绿色 "Code" 按钮 → "Download ZIP"
3. 解压到任意位置（比如桌面）

═══════════════════════════════════════
第 2 步：放入模型文件（微信发你的 checkpoints.zip）
═══════════════════════════════════════
1. 你会收到一个压缩包：checkpoints.zip（约 4.5MB）
2. 把它解压到代码的 dqn_2d_standalone 文件夹里
   （解压后会自动形成 dqn_2d_standalone\checkpoints\ 文件夹，
     里面应有 50 多个 .pt 文件，其中一个叫 nav100_3obs_init.pt）

═══════════════════════════════════════
第 3 步：双击运行【1_安装环境.bat】（只需一次）
═══════════════════════════════════════
- 会自动创建虚拟环境并安装依赖，torch 比较大，耐心等几分钟
- 看到"安装完成"就可以关掉窗口

═══════════════════════════════════════
第 4 步：双击运行【2_开始训练.bat】
═══════════════════════════════════════
- 会自动依次完成：任务1 训练3000轮 → 任务1 评估 → 任务2 训练3000轮 → 任务2 评估
- 全程无需操作，日志滚动属正常
- 想中断可按 Ctrl+C（每 100 轮自动存档，不会全丢）

═══════════════════════════════════════
第 5 步：把结果发回来（共 4 个文件，都很小）
═══════════════════════════════════════
1. dqn_2d_standalone\eval_lc002_final.csv
2. dqn_2d_standalone\eval_lc005_final.csv
3. dqn_2d_standalone\checkpoints\curr_3obs_lc_final.pt
4. dqn_2d_standalone\checkpoints\curr_3obs_lc05_final.pt

【常见问题】
Q: 我有显卡，为什么好像没用到？
A: 正常。这个实验环境是纯运动学计算，主要吃 CPU，显卡用不上不影响结果。

Q: 提示 "python 不是内部或外部命令"？
A: 第 0 步安装时没勾 "Add python.exe to PATH"，重装一遍 Python 并勾上。

Q: 中途想停怎么办？
A: 在训练窗口按 Ctrl+C。中断后请先联系项目方再决定怎么处理，
   不要直接重新双击（会从头开始）。
